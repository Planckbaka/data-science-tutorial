# Agent 平台对比笔记

## Dify vs Coze vs n8n

| 维度 | Dify | Coze (扣子) | n8n |
|------|------|------------|-----|
| **公司** | Dify.AI (开源) | 字节跳动 | n8n GmbH (开源) |
| **核心定位** | AI 应用开发平台 | C端智能体平台 | 通用工作流自动化 |
| **开源** | ✅ Apache 2.0 | ❌ 闭源 | ✅ 可自部署 |
| **RAG** | 内置完善（多种检索模式） | 知识库功能 | Vector Store 节点 |
| **Agent** | 支持 ReAct | 内置 Agent 模式 | AI Agent 节点 |
| **工作流** | 可视化拖拽 | 可视化拖拽 | 可视化拖拽（500+节点） |
| **模型支持** | OpenAI/Claude/通义/本地 | 字节模型+OpenAI | 多模型 |
| **发布渠道** | API/嵌入 | 抖音/微信/飞书/Web | Webhook/API |
| **外部集成** | API 为主 | 插件市场 | 500+ 原生集成 |
| **记忆** | 对话历史 | 长期记忆+变量 | Memory 节点 |
| **最适合** | B端 AI 应用/RAG | C端 Bot/客服 | 系统间自动化+AI |

## 选型建议

- **快速搭建 RAG 知识库** → Dify（最完善的 RAG 支持）
- **面向 C 端用户的 Bot** → Coze（丰富的发布渠道）
- **连接多系统的自动化 + AI** → n8n（500+ 集成）
- **需要完全控制和自部署** → Dify 或 n8n（开源）
- **需要深度定制 Agent 逻辑** → LangGraph/AutoGen 代码实现

## 面试回答模板

> "三个平台各有侧重：Dify 适合 B 端 AI 应用开发，RAG 能力最强，且开源可自部署；
> Coze 面向 C 端，有丰富的插件和发布渠道（抖音、微信）；
> n8n 是通用自动化工具，擅长连接多个外部系统。
> 实际项目中可以组合使用：n8n 做数据流转和触发，Dify 做 AI 核心逻辑。
> 但对于复杂的 Agent 逻辑，还是需要 LangGraph 等代码框架来实现精细控制。"
